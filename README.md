# Brainxiex Bot WhatsApp

![Brainxiex Development Logo](asset/banner.jpg)

Bot WhatsApp multifungsi berbasis Node.js, dikembangkan oleh Brainxiex Development. Mendukung berbagai fitur otomatisasi, game, AI, utilitas grup, dan personal assistant.

## Fitur Utama

- **Game & Fun:** Tebak-tebakan, slot, hack, lirik, watak, zodiak, dan lainnya.
- **AI & Image:** Chat AI, generate gambar, remini, toanime, gpt, bard, dll.
- **Grup Admin:** Warn/unwarn, promote/demote, kick, blacklist, approveall, afk, limit, daily.
- **Tools:** Screenshot, nulis, infoip, subdomain, igstalk, id, converter media.
- **Bank & RPG:** Dompet, bank, tabung, tarik, pekerjaan, levelup, inventory, claim, panen, shop.
- **VIP & Owner:** Fitur eksklusif untuk VIP dan owner, seperti join grup, unblock, eval, restart, broadcast.
- **Downloader:** YouTube, TikTok, Instagram, Facebook, Twitter, Pinterest, dll.
- **Sticker & Converter:** Sticker, emojimix, brat, fakechat, toimage, tolink, tourl.
- **Rules & Anti:** Antitoxic, antiwame, antitagall, antilinkgrup, antidelete, antispam.

## Instalasi

1. **Clone Repository**
   ```
   git clone https://github.com/Barqah-Xiex/brainxiex-bot-whatsapp.git
   cd brainxiex-bot-whatsapp
   ```

2. **Install Dependencies**
   ```
   npm install
   ```

3. **Konfigurasi**
   - Edit file `config.js` sesuai kebutuhan (API key, owner, dll).
   - **Pembelian API key dapat dilakukan di** [https://xiex.my.id/api](https://xiex.my.id/api)

4. **Jalankan Bot**
   ```
   node index.js
   ```

## Struktur Folder

- `fitur/` : Semua fitur bot (Game, Fun, Tools, AI, Grup, dll)
- `addons/` : Modul tambahan (helper, database, rpg, dll)
- `cmd/` : Command sederhana/respon cepat
- `event/` : Handler event WhatsApp (welcome, waktu sholat, dsb)
- `asset/` : Gambar/logo/dll
- `database/` : Data persistent (user, grup, log, dsb)
